使用Exchange Web Services來存取Exchange服務

發表於2010-07-19|更新於2026-09-26
|總字數:910|閱讀時間:4 分鐘|瀏覽量:

最近公司的信箱因為申請改成了Exchange服務，信箱變大，也有比較好的介面(原來的只有200M，Mail2000的介面)。不過謎之程式(自動轉信程式)因為使用Exchange而不能使用。雖然原來使用的Email函式庫可以直接存取Exchange的信件伺服器，但也因為安全問題而無法直接存取。在網路上找呀找，最後找到Exchange Web Services(EWS)，試了一下又可以繼續Work了，也分享給大家。

首先使用之前，記得原來Exchange的憑證要匯入到執行程式的系統中，並且設定為受信任根憑證，要不然會無法執行。

另外Outlook Web Access(OWA)服務記得要先使用過一次，要不然會有奇怪無法執行的問題。我把程式給了同事，在同事的電腦上不能跑，直到上了公司的OWA，才可以跑。

開發部分從這裡知道需安裝Exchange Web Services Managed API，開一個專案，記得要引用安裝目錄下的dll檔(Microsoft.Exchange.WebServices.Data.dll)，並且using/imports到程式裡。

接下來是程式內容的部份。原來的流程是把全部在收件夾的信件，轉到gmail去，並且在Server上不留備份。不過我們公司的EWS好像不支援寄信(擋權限)，所以就交給原來的程式內容繼續做，只需改一開始用POP3 Server接收信件的部份，變成連結EWS取信件。
