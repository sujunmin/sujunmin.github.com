試玩了一下 VMWare Photon 1.0

發表於2016-06-17|更新於2026-10-02
|總字數:234|閱讀時間:1 分鐘|瀏覽量:

今天早上看到這個，想說有空來試玩一下，以下是我的心得。

  1. 官網。
  2. 我是下載 Photon OS, Version 1.0 — OVA with virtual hardware v11，懶得自己裝了。
  3. 用 VMWare Workstation 匯入，看起來蠻小的 (2G Ram, 1 Core)。
  4. 跑起來以後會先設定 root 密碼 (預設是 changeme，登入以後馬上會修改)。
  5. 預設有開 ssh，可用其他程式連線。
  6. Yum 系的 package manager，但是改成了 tdnf 。
  7. 設定 IP /etc/systemd/network/10-dhcp-en.network 裡頭修改 Network。
  8. 開始玩 docker，Q. I just booted into freshly installed Photon OS instance, why isn’t “docker ps” working?
  9. 啟動 docker 與 port exposed。
  1. 在上面起 asp.net core 1.0 程式，推荐這個，記得 Program.cs 裡頭要多加東西再 build。
  1. 用瀏覽器測試一下。
  2. 基本上啟動還蠻快的，kernel 不大，不知道匯到 vSphere/Esxi 上有沒有什麼神奇功能，有時間再試試看。

Ubuntu 16.04 關機變成登出的解法
現在家裡的機器與公司的工作機大多是用 Ubuntu 來作業的(公司的工作機開 VM)，安裝完 Ubuntu 16.04 後就安裝了 Macbuntu 妝點一下桌面，結果發現到原來右上角的關機鍵變成了登出了。 原來以為是主題的關係，更新了幾次還是這樣，今天就想來抽絲剝繭一下問題到底在哪。 在經過 Google 的處理(XD)以後，發現到是中間的 Plank Docker 衝到系統了，所以要延遲系統登入時自動執行 Plank 的時間。 在 ~/.config/autostart/plank.desktop 裡頭裡加入一段 X-GNOME-Autostart-Delay=20 其中 20 表示延遲 20 秒載入，這樣就會恢復可以關機了。
