需求說明

在開發某個應用的時候，使用 LINE Notify 作為通知功能，卻發現到該架構沒有使用 Web API 的函式 (Webrequest, HttpWebRequest, RestGet, …)，透過執行外部程式的方式來達成目的。

LINE Notify

這個服務蠻方便的，如果要作簡易的通知機器人又不想要作複雜的機器人開發，只要註冊一下就可以使用了，Google 一下有很多人都有使用經驗，是個不錯的服務。
